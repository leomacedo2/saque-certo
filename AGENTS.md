# Rotina de entrega

- Ao concluir uma nova versão do Saque Certo, executar `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\backup.ps1` na raiz do projeto.
- Manter backups em `C:\Users\Leonardo\Desktop\MinhaVida\VSCodeNew\SaqueCertoBackups`, preservando todas as versões anteriores.
- Conferir se o ZIP foi criado e pode ser aberto antes de informar que o backup está pronto.
- Atualizar a versão do `package.json` quando uma nova versão do aplicativo for entregue.
